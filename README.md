# kawsarhamid99.github.io

Personal portfolio site — [kawsarhamid99.github.io](https://kawsarhamid99.github.io)

Single-page, no build step. Everything lives in `index.html` (styles are inline in a `<style>` block).

## Editing

Open `index.html` and edit the content directly. Sections in order:
`hero` → `#work` → `#research` → `#experience` → `#skills` → `#contact`

To add a project, copy an existing `<article class="card">` block inside `.grid.two`.

## Publishing

Pushing to `main` redeploys automatically via GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
